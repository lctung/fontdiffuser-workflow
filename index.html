FontDiffuser

One-Shot Font Generation via Denoising Diffusion with Multi-Scale Content Aggregation and Style Contrastive Learning

Zhenhua Yang1, Dezhi Peng1, Yuxin Kong1, Yuyi Zhang1, Cong Yao3, Lianwen Jin1,2
1South China University of Technology, 2SCUT-Zhuhai Institute of Modern Industrial Innovation, 3Alibaba Group
Paper arXiv Video Code Data

製作流程

1. 製作稿紙 2. 稿紙裁切 3. FontDiffuser 生成 4. 向量化 5. 字體打包

1. 製作稿紙

整理需要手寫的文字內容，產生包含指定字元與 QR Code 的手寫稿紙， 再輸出成 PDF 供學生書寫。

Input

稿紙文字內容

Output

PDF 手寫稿紙

2. 稿紙裁切

將完成書寫的稿紙進行旋轉校正，依照稿紙中的字元位置切割， 取得單字影像作為後續字體生成的資料。

Input

手寫稿紙掃描檔

Output

單字 PNG 影像

3. FontDiffuser 生成

將手寫字影像整理成模型所需的資料格式，透過 FontDiffuser 進行訓練與生成，補足未實際書寫的字元。

Input

手寫字資料集

Output

生成字元 PNG

4. 字形向量化

將生成的 PNG 字形轉換為 SVG 向量圖形，並進行 SVG 格式處理，讓字形能夠進一步進行字體打包。

Input

字元 PNG 影像

Output

SVG 字形

5. 字體打包

將 SVG 字形整理並合併，最後透過 FontForge 設定字體資訊與 CP950 字碼頁，輸出可安裝與使用的 TTF 手寫字體。

Input

SVG 字形

Output

TTF 手寫字體

專案程式碼： 製作稿紙 · 稿紙裁切 · FontDiffuser · 字形向量化 · 字體打包
